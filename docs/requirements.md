# このプロダクトで成し遂げること

## 目的

自宅に設置したPanasonic i-PROネットワークカメラ（WV-S1531L、WV-S3530）のSDカード録画を、カメラのHTTPインタフェース経由で定期的に取得し、安全に保管できるようにする。既存のPython+bash実装をGoで再構成し、単一バイナリで運用できる形にする。

## 実行モデル（決定）

- コンテナイメージとして配布し、**ワンショット実行**（CronJob等から起動、実行したら終了）する。常駐デーモンにはしない
- **高頻度（5分間隔程度）で実行**し、新しい録画があればダウンロードしてローカルに溜める
  - 人感検知で1時間に何度も録画されるため、1時間に1回の取得では録画ログが1ページに収まらず、2ページ目以降の取得が必要になる。高頻度実行により、1回の実行で見るのは直近の差分だけにしてページ送りを避ける（ページ送りへの対応自体も堅牢性のため検討する）
- ローカル保存先は永続ボリューム（VMのディスク、またはK8s StatefulSetのPVC）を前提とする。増分管理の状態もここに置く
- **設定値に応じて、1時間に1回程度、溜まった動画をAWS S3へ出力**する。出力済みのローカルファイルは整理（削除）できる。S3以外のクラウドストレージは将来の拡張余地とし、現時点ではS3のみ

## スコープ

### コア

- 複数カメラの設定読込（ホスト、認証、保存先）
- [protocol.md](protocol.md)の手順による録画ログ取得と動画ダウンロード
- 増分取得（取得済みの録画は再取得しない）。失敗時に取りこぼさない。ワンショット実行が重なっても壊れない（排他制御）
- ストリーミング保存、一時ファイル経由の原子的な保存
- カメラ単位のエラー分離、タイムアウト・リトライ
- 構造化ログ

### S3出力

- 設定した間隔（既定は1時間）が経過していれば、同一バイナリ内でローカルの動画をまとめてS3へアップロード
- アップロード間隔・対象期間・アップロード後のローカル削除の有無は設定値で制御
- 既存の`zip-movie.sh`相当（時間単位のzip化、`{カメラ名}/{yyyy}/{yyyymm}/{yyyymmdd}/`配下）を踏襲するか見直すかは未決

### 対象外（現時点）

- ライブ映像の取得・配信
- カメラ設定の変更
- 動画の再エンコード・解析
- 常駐プロセス（デーモン）化
